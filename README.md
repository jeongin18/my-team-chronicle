# 나의 팀 연대기 · 프로야구로 읽는 한국 현대사

고1 한국사1 2~3차시용 개인 활동 웹앱입니다. 학생은 구단 하나를 골라 그 팀의 역사를 따라가며 미션을 풀고, 마지막에 「우리 구단 박물관」 전시 라벨을 씁니다. 교사는 전자칠판에서 실시간 순위·구단 응원 점수·전시 라벨 갤러리를 봅니다.

## 파일 구성

| 파일 | 하는 일 |
| --- | --- |
| `index.html`, `app.js`, `style.css` | 학생 화면 (크롬북·아이패드) |
| `teacher.html`, `teacher.js` | 교사 전광판 (비밀번호 입장) |
| `index.html?board=1` | 전자칠판용 튜토리얼 화면 (로그인 없이 연습 5문항) |
| `config.js` | Firebase 설정, 교사 비밀번호, 저장 위치 이름 |
| `store.js` | 저장 담당 (Firebase가 없으면 체험 모드) |
| `data/game-data.js` | 문항 데이터 (콘텐츠 검토표에서 자동 추출) |
| `firestore.rules` | Firestore 보안 규칙 |
| `logos/` | 구단 로고 넣는 곳 (`lg.png` 등, 없으면 약칭 배지) |
| `images/stadium/` | 구장 사진 넣는 곳 (`lg.jpg` 등, 없으면 그림) |
| `images/credits.js` | 구장 사진 출처·라이선스 표기 |

## 1. Firebase 준비 (무료, 약 10분)

1. https://console.firebase.google.com 에서 **프로젝트 추가** (Google 애널리틱스는 꺼도 됩니다).
2. 왼쪽 **빌드 → Firestore Database → 데이터베이스 만들기** → 위치 `asia-northeast3 (서울)` → **프로덕션 모드**.
3. Firestore의 **규칙** 탭에 `firestore.rules` 내용을 붙여 넣고 **게시**.
4. 프로젝트 설정(톱니바퀴) → **내 앱 → 웹(</>)** → 앱 등록 → 나오는 `firebaseConfig` 값을 `config.js`의 `firebase` 칸에 붙여 넣기.
5. `config.js`의 `teacherPin`(교사 비밀번호)을 바꿉니다.

`config.js`의 `collection` 이름을 바꾸면 `firestore.rules`의 `match /chronicle-2026/{sid}`도 같은 이름으로 바꿔야 합니다.

## 2. GitHub → Vercel 배포

1. GitHub에서 새 저장소를 만들고 이 폴더의 파일을 모두 올립니다(웹에서 **Add file → Upload files**로 끌어다 놓기).
2. https://vercel.com → **Add New → Project** → 그 저장소 **Import** → Framework Preset은 **Other**, 나머지는 그대로 **Deploy**.
3. 나온 주소(예: `https://my-team-chronicle.vercel.app`)를 학생에게 안내합니다. 교사 화면은 같은 주소 뒤에 `/teacher.html`.

파일을 고쳐 GitHub에 다시 올리면 Vercel이 1분 안에 자동으로 다시 배포합니다.

## 3. 수업 흐름

| 시간 | 학생 | 교사 화면 |
| --- | --- | --- |
| 1차시 도입 10분 | 학번·이름으로 입장 | `튜토리얼 띄우기`로 연습 5문항을 함께 풀기 |
| 1~3차시 | 구단 선택 → 3챕터 미션 (구단마다 25~35개) | 개인 순위, 구단 응원 점수 |
| 3차시 마지막 15분 | 나의 한 장면 → 전시 라벨 3줄 | 전시 라벨 갤러리, 나의 한 장면 |

학생이 '제출'을 누르지 않아도 한 문항을 풀 때마다 기록이 저장됩니다. 창을 닫았다가 같은 학번·이름으로 들어오면 이어서 합니다.

## 점수 규칙

- 객관식: 한 번에 맞히면 10점, 두 번째 7점, 세 번째 4점. 틀릴 때마다 고른 선택지가 지워지고, 두 번 틀리면 오답 하나가 더 지워집니다.
- 지도 퍼즐: 깃발마다 첫 시도에 맞히면 몫 전체, 두 번째는 절반.
- 카드 배치: 제자리에 놓은 카드 비율만큼 점수.
- 명장면 재현(타이밍 게임): 공 3개, 맞힐 때마다 보너스 1점. 보너스는 구단 만점의 3% 안팎입니다.
- 순위는 만점 대비 백분율이라 미션 수가 적은 구단(NC·KT·키움)도 불리하지 않습니다.
- 팬 등급: 25% 미만 신입 팬 · 25% 직관러 · 50% 골수 팬 · 75% 레전드 팬.
- 나의 한 장면, 전시 라벨은 점수에 들어가지 않습니다.

## 체험 모드

`config.js`의 `apiKey`가 비어 있으면 체험 모드입니다. 기록이 그 브라우저에만 저장되고, 같은 브라우저에서 연 교사 화면에만 보입니다. 수업 전 미리 해 보기용입니다.

## 데이터 지우기

학기가 끝나면 Firebase 콘솔 → Firestore → `chronicle-2026` 컬렉션을 삭제하세요. 다음 학기에는 `config.js`와 `firestore.rules`의 컬렉션 이름을 바꿔서 쓰면 기록이 섞이지 않습니다.

## 문항 고치기

문항은 Claude Docs의 「나의 팀 연대기」 콘텐츠 검토표를 기준으로 `data/game-data.js`에 들어 있습니다. 한두 문항은 이 파일을 직접 고쳐도 됩니다(각 미션의 `options` 첫 번째가 정답이고, 화면에서는 섞여서 나옵니다).


## 2026-11-11 업데이트
- 틀리면 선택지를 지우지 않고 힌트를 보여 줘요(10 → 7 → 4점).
- 연대기 카드를 누르면 질문·정답·해설·출처를 다시 읽어요.
- '카드 배치'를 '짝 맞추기(원인·상황 ↔ 결과·배경)'로 바꿨어요.
- 지도는 Natural Earth 1:10m 해안선(퍼블릭 도메인)을 써요: data/map-data.js.
- 명장면 재현은 Three.js(MIT 라이선스, vendor/ 폴더) 3D 야구장이에요. 타격 장면은 포수 뒤 중계 시점, 투구 장면은 중견수 쪽 망원 중계 시점이에요. WebGL이 안 되는 기기에서는 2D 화면으로 자동 전환돼요.
- 명장면은 한 타석 승부예요: 볼카운트(B·S·O), 파울, 볼넷·삼진, 타이밍에 따라 안타·2루타·홈런. 전광판에 이닝·주자·점수·목표가 나오고 중계 자막이 흘러요. 목표 달성 3점, 아니면 결과에 따라 0~2점(전체의 10% 이하).
- models/ 폴더에 Mixamo FBX를 넣으면 도형 선수 대신 실제 사람 모양 선수와 동작이 나와요(models/README.txt).
- images/missions/ 폴더에 미션ID.jpg를 넣으면 문제 화면에 사진이 나와요(README_사진_추천.md).
- images/stadium/<구단>.jpg 를 넣으면 그려진 구장 그림 대신 사진이 나와요.
- 문항별 힌트·단서·짝 목록은 README_힌트·단서·짝맞추기.md 에 있어요.
- 진행 중에도 위쪽 막대의 🏠 홈 / 📚 챕터 버튼으로 홈(내 점수·카드 모음)이나 챕터 선택 화면으로 갈 수 있어요. 마무리(전시 라벨)는 세 챕터를 모두 끝내면 열려요. (홈 · 챕터)
- 명장면 재현은 시작 전에 난이도(쉬움·보통·어려움)를 골라요. 보통부터는 슬라이더·체인지업과 볼이 섞이고(볼을 골라내도 성공), 어려움은 커브까지 나오고 타이밍 게이지가 사라져요.
- 홈 화면의 '🎮 단장 시뮬레이션'(10개 구단, 구단별 3~5장면): 실제 위기에서 선택 → 팬 민심·재정·전력 게이지 변화(가상의 값) → 실제 역사·출처 → 토론 질문. 교사 전광판 '단장 시뮬레이션' 탭에서 칭호 분포와 장면별 '실제와 같은 선택' 비율을 봐요. 내용은 scripts/gm.py에 있어요.
