# 미션 사진 넣기 안내 (선생님용)

문제 화면에 시각 자료를 보여 주려면 이 폴더에 `미션ID.jpg`(예: `M2.jpg`, `K17.jpg`) 파일을 넣으세요.
파일이 있으면 문제 위에 자동으로 나타나고, 없으면 아무것도 표시되지 않아요.

출처 표기: `images/credits.js`의 `IMAGE_CREDITS`에 `"m:미션ID": "저작자 / 라이선스 / 출처"` 형식으로 적어 주세요.

## 원칙
- 실존 인물(선수·정치인) 얼굴이 중심인 사진은 넣지 않아요. 구장·물건·지도·문서 사진을 권해요.
- 저작권이 분명한 자료만: 위키미디어 공용(CC BY / CC BY-SA / 퍼블릭 도메인), 공공누리 1유형, 직접 찍은 사진.
- 언론사 보도 사진은 넣지 말고 문제의 출처 링크로 연결해요.
