# 나의 팀 연대기 – 힌트·단서·짝 맞추기 (2026-11-11)

선생님 피드백 15가지를 앱에 반영하면서 바뀐 내용이에요. 앱은 이 검토표에 아래 수정을 덧입혀 만들어요.

### 바뀐 규칙

- 객관식에서 틀리면 선택지를 지우지 않고 힌트를 보여 줘요. 한 번에 맞히면 10점, 힌트를 보고 두 번째 7점, 세 번째 4점이에요.
- 숫자 선택지는 섞지 않아요. 연도는 오래된 것부터, 개수·순위·햇수는 큰 것부터 위에 놓아요.
- 연대기 카드를 누르면 질문·정답·해설·출처를 다시 읽을 수 있어요. F1은 '사례 더 보기', K7은 정답 뒤 보안사 문건 요지를 보여 줘요(원본 사진은 YTN 기사 링크로 확인).
- 시구자 후보에서 정우성을 뺐어요(F3·F4).

### 고친 문항

- K16: 해태제과와 '홈런볼'을 사료로, 1980년대 소비재 기업들이 야구단에 회사·상품 이름을 붙인 까닭(홍보)을 추론하는 문항으로 바꿨어요. 정답은 '야구 인기를 타고 회사와 상품을 널리 알리려고'예요. 출처: [머니투데이(2025)](https://www.mt.co.kr/living/2025/11/15/2025111316392268220), [토스피드(2024)](https://toss.im/tossfeed/article/behindthemoney-8)

### 삭제한 문항

중복이거나 연도만 줄 세우는 활동이라 뺐어요: M14, S15, S25, K19, K24, K25, D14, D19, D25, G13, G25, W14.

### 2차 정리(2026-11-11 오후)

- 답을 바로 알려 주던 '처음부터 보이는 단서'(특히 우승 연도 목록)는 빼고, 틀렸을 때 보여 주는 힌트로 옮겼어요: M11, S16, K3, K15, K20, D9, D15, G7, G10, G15, L5, L13, L16, H4, H6, H20, N8, R10, R11, R12, W8, W11, W12.
- 발문 속 '(힌트: …)' 가운데 답을 거의 알려 주던 것은 틀렸을 때 힌트로 옮겼어요: M19, M26, S2, S19, S20, K21, G2, G12, L2, L19, L22, H15, F17. 추론에 꼭 필요한 정보(예: H19 '직전 진출은 류현진의 첫해')는 단서 상자로 남겼어요.
- 선택지에 답이 드러나던 N6·G11의 괄호 설명을 뺐고, K22의 어색한 오답을 바꿨어요.
- 구장 탐방 K17·S13·L24·R9에 '눌러 보는 정보 카드'를 넣었어요(K17 출처: OSEN 2014-01-03, S13 출처: 매일신문).
