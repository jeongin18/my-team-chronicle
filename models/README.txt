[선택] 실제 사람 모양 3D 선수 넣기 (Mixamo, 무료)

1. https://www.mixamo.com 에 Adobe 계정으로 로그인
2. Characters 탭에서 마음에 드는 캐릭터 1개 선택 → Download
   Format: FBX Binary(.fbx) / Pose: T-pose → 파일 이름을 player.fbx 로 바꿔 이 폴더에 넣기
3. Animations 탭에서 아래를 검색해 각각 Download (Skin: Without Skin, 30 fps)
   - "Baseball Idle"    → idle.fbx
   - "Baseball Hit"     → swing.fbx
   - "Baseball Pitching"→ pitch.fbx
   - (선택) "Baseball Catcher" 류 → catcher.fbx
4. models 폴더 구성:  player.fbx  idle.fbx  swing.fbx  pitch.fbx  (catcher.fbx)

파일이 없으면 지금처럼 기본(도형) 선수로 자동 대체돼요.
Mixamo 캐릭터·애니메이션은 Adobe 이용 약관에 따라 프로젝트에 무료로 쓸 수 있어요(약관은 직접 확인해 주세요).
